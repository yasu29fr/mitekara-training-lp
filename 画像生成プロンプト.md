# ミテカラ 社内研修 LP 画像 生成プロンプト（11点）

対象：`mitekara-training-資料/LP/index.html` 内の写真11点。掲載順。
生成したら `images/` の**同じファイル名で上書き**すれば、HTMLは触らずに差し替わります。

※ 元のミテカラ（採用）LP用のプロンプトは `_保留（…）/画像生成プロンプト（ミテカラ本番LP用）.md` に控えてあります。

---

## 全画像に共通する条件（プロンプト冒頭に付ける）

```
Photorealistic editorial corporate photograph taken in Japan, Japanese workplace, natural daylight or clean indoor lighting, soft shadows, slightly warm and calm color grading, shot on 35mm lens, shallow depth of field, candid and unposed, no text, no letters, no logos, no watermark, no signage, high resolution
```

共通ネガティブプロンプト：

```
text, letters, logo, watermark, signage, name tags with text, western office interior, extra fingers, deformed hands, distorted face, oversaturated, HDR look, stock-photo pose, thumbs up, arms crossed, cluttered background, low resolution, blurry face
```

### トーンの指定（採用LPと変える）

- 採用LPは**紺 × 橙**。研修LPは**深緑 `#1f5c4c` × 金 `#b7791f`**。**背景や服に強い青・鮮やかなオレンジを入れない**
- 服装は、作業着＝グレー／ネイビー／生成り、事務＝白・グレー・ベージュ。**深緑の作業着や小物が少し入ると馴染む**
- 人物は**20代〜50代を混ぜる**。採用LPは若手だけだったが、研修は新人とベテランの両方が出るほうが正しい
- **外国人実習生を2〜3点に必ず入れる**（東南アジア系の若い男女）。商品の柱なので、写真に無いと言葉だけになる
- 学生・リクルートスーツ・就職活動を思わせる要素は入れない

- 意図：勤務時間の中で、手が空いたときに研修を受けている

## 差し替え手順

1. 生成画像を `mitekara-training-資料/LP/images/` に**同じファイル名で上書き保存**
   （`hero.jpg` / `problem.jpg` / `video-01.jpg` / `video-02.jpg` / `video-03.jpg` /
   　`reason-01.jpg` / `reason-02.jpg` / `reason-03.jpg` / `system.jpg` / `prep.jpg` / `contact.jpg`）
2. `LPを見る.command` で確認
3. よければ `LPを公開.command` で公開

**画像は書き出す前に長辺2000px以下・JPEG品質80%程度に落としてください。** 1点1MBを超えると読み込みが目に見えて遅くなります。

## 画面キャプチャ3点は、別途

写真ではなく管理画面のスクリーンショットです。いまは**説明会ツールの画面のまま**なので、研修ツール（`mitekara-training.vercel.app`）の実画面に差し替える必要があります。

| ファイル | 差し替え元 |
|---|---|
| `screen-student.png` | 受講者側 `/learn/<コース>`（スマホ幅で撮る。章とレッスンが並んだ画面） |
| `screen-recruiter.jpg` | 管理画面 `/admin/progress`（受講状況の一覧） |
| `screen-dashboard.jpg` | 管理画面 `/admin/progress` の上部（対象者・修了・受講中・未着手の集計） |

**撮る前に、表示されている氏名とメールアドレスをダミーに差し替えてください。** LPは公開ページなので、実データが写り込むと事故になります。
